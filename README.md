# AC Square — website

Open `index.html` to view the site. To publish, upload the whole folder to any static host (Netlify, Vercel, GitHub Pages, Cloudflare Pages, or regular web hosting).

- Copy and content: `index.html`
- Colours, fonts, layout: `css/styles.css` (brand colours are at the top)
- Hero examples, rotation speed, contact email: top of `js/main.js`

See `CLAUDE.md` for the full structure. It's written so Claude Code (or any developer) can pick the site up and edit it.
